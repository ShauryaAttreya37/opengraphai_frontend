Pipeline

Five steps from files to a graph.

Every step is swappable. Bring your own extractor, model, embeddings, or graph store. OpenGraph AI connects them into one context layer an agent can query.

Read the quickstart → Explore resources

01 · pipeline

One path across every modality.

Normalize raw inputs, preserve provenance, resolve entities across sources, and give agents a compact subgraph instead of a wall of chunks.

  1. 01Ingest

    Point at your data.

    PDFs, CSVs, JSON, audio, video, images, URLs, buckets, and databases enter through a unified loader that keeps source metadata attached.

  2. 02Extract

    Read every modality.

    Parse tables, transcribe recordings, caption images, and segment documents into typed entities, relationships, and timestamped citations.

  3. 03Link

    Resolve shared entities.

    The same company mentioned in a deck, call, and spreadsheet becomes one node. Cross-modal links make hidden relationships explicit.

  4. 04Persist

    Store the context graph.

    Keep a versioned property graph with evidence and embeddings. Export to graph stores or use the portable graph directly inside your agent stack.

  5. 05Query

    Ask, traverse, cite.

    Turn natural-language questions into graph walks. Return a ranked subgraph plus citations, or expose the graph as one tool for an agent.

03 · interfaces

Use it where you already work.

Build from Python or TypeScript, run from the CLI, serve through REST, or connect the MCP server to an agent-compatible IDE.

Python

from opengraph import Graph

graph = Graph()
graph.ingest("./customers/**/*")
graph.ask("Top churn risks and why?")

TypeScript

import { Graph } from "opengraph-ai";

const graph = await Graph.fromSources([
  "s3://acme/calls/*.mp3",
]);
await graph.ask("Who flagged pricing risk?");
