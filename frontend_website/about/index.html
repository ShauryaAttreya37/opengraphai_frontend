The open context layer for reasoning agents.

01 · why

Retrieval should preserve relationships.

Retrieval-augmented agents often flatten real context into text chunks. That loses the structure connecting people, claims, events, sources, and evidence. OpenGraph AI keeps that structure available as a graph.

02 · principles

Built to compose, not control.

  • Open by default

    Inspect and self-host the core. Your graph remains portable.

  • Modality-agnostic

    If a model can read it, the pipeline should be able to graph it.

  • Composable

    Bring your preferred extractor, model, embeddings, and graph store.

  • Agent-native

    Designed as a context tool an agent calls, not another interface it babysits.
