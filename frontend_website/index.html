ABOUT

The open context layer for reasoning agents.

We started OpenGraph AI because retrieval-augmented agents are stuck on text. Real problems live across tables, slides, recordings, and screenshots — and the answers live in the relationships between them. We're building a single, open graph layer so agents can reason across all of it.

Principles

  • Open by default Apache-2.0 core. Self-host or use the hosted version. Your graph is portable.
  • Modality-agnostic If a model can read it, we can graph it. Tables, text, image, audio, video, code.
  • Composable Bring your own extractor, LLM, embeddings, or graph store. We orchestrate.
  • Agent-native Designed to be a single tool an agent reaches for — not a service it babysits.

✦ MULTIMODAL BY DESIGN 05 → 01

Five kinds of context. One place to reason.

OpenGraph AI understands each source in its native form, then connects what they say into context an agent can query and cite.

  • Text

    Documents, PDFs, and URLs become entities, concepts, and source-backed claims.

  • Tables

    Rows and columns become structured records with explicit relationships.

  • Images

    Objects, labels, and visual context join the same connected entity space.

  • Audio

    Calls and recordings become searchable speakers, signals, and referenced facts.

  • Video

    Scenes and time-based events connect back to people, objects, and claims.
